# Wearable Physiological Signals for Procedural Pain Prediction

Code repository for: **"Predicting Patient-, Nurse-, and Physician-Rated Pain During Lumbar Procedures: A Multi-Rater Evaluation of Wrist-Worn Physiological Signals and Procedural Context"**

Submitted to: *JMIR mHealth and uHealth*

## Overview

This repository contains all code for preprocessing physiological signals (electrodermal activity, heart rate, photoplethysmogram amplitude, skin temperature, motion) from wrist-worn devices (Empatica E4 and EmbracePlus) and evaluating pain prediction models with leave-one-patient-out cross-validation.

**Key Finding:** Wrist-worn physiological signals did not predict pain scores better than a training-mean baseline (R² −0.09 to −0.07), whereas procedural context explained 44–56% of variance. Adding physiology to context made predictions worse (ΔMAE +0.31 NRS points, 95% CI 0.11 to 0.53).

## Preprocessing Pipeline

The preprocessing pipeline converts raw device data into analysis-ready features:

### Step 1: Process Device Signals
```bash
# Process Empatica E4 data (sessions 1-15)
python preprocessing/process_e4.py --input data/raw --output data/processed

# Process EmbracePlus data (sessions 16-24)
python preprocessing/process_embraceplus.py --input data/raw --output data/processed
```

**Signal Processing:**
- **EDA:** Low-pass filter (1 Hz cutoff), phasic decomposition (cvxEDA), SCR detection
- **Heart Rate:** IBI cleaning (physiological range 300-2000 ms), robust HR estimation
- **BVP Amplitude:** Envelope detection (Hilbert transform)
- **Temperature:** Median filter (5-sample window)
- **Motion:** 3-axis accelerometer magnitude
- **Robust Scaling:** All signals scaled within-session (median/IQR, capped at ±5)

### Step 2: Align Pain Assessments
```bash
python preprocessing/align_ratings.py --signals data/processed --ratings data/raw --output data/processed
```

Aligns recorded pain scores (patient, nurse, physician) with physiological signals using manual timestamps, correcting for device clock drift.

### Step 3: Extract Features
```bash
python preprocessing/extract_features.py --input data/processed --output data/processed
```

For each pain assessment, extracts features from:
- **Response window:** −30 to +90 sec around recorded time
- **Reference window:** −180 to −30 sec (pre-assessment baseline)

**Features per signal (6 stats × 5 modalities = 30 features):**
- `level`: mean of response window
- `max`: maximum value
- `std`: standard deviation
- `slope`: linear trend (OLS)
- `delta`: response mean minus reference mean
- `peak_rise`: maximum minus reference mean

**Additional features:**
- EDA: SCR count, mean SCR amplitude (response window)
- Context: assessment type (baseline/procedural/post), event index, minutes from procedure start (5 features)

**Total:** 32 physiological + 5 context = 37 features per assessment

### Step 4: Build Analysis Dataset
```bash
python preprocessing/build_dataset.py --input data/processed --output data/processed/events_features.csv
```

Combines all features into a single CSV with columns:
- `subject`, `session`, `patient` (unique patient ID across sessions), `event_idx`, `category`, `min_from_proc_start`, `device`
- Pain scores: `pain_patient`, `pain_nurse`, `pain_physician`
- 37 features (32 physiological + 5 context)
- Quality flags: `in_recording`, `has_eda`, `has_hr`, `has_bvp`, `has_temp`

## Primary Analysis

### Regression Models (Table 4, Figure 3)
```bash
python analysis/jmir_analysis.py
```

**Design:**
- **Unit:** one assessment (no sliding windows)
- **Models:** ridge regression (α ∈ {1,10,100,1000}), random forest, XGBoost
- **Validation:** leave-one-patient-out with nested hyperparameter selection (inner 4-fold GroupKFold)
- **Feature sets:** physiological (no motion), context, combined
- **Baselines:** training-mean (regression), training-prior (classification)
- **Metrics:** R², MAE, within-patient Spearman ρ (with patient-level bootstrap 95% CIs)

**Outputs:**
- `out/jmir_revised/performance_ci.csv` — all metrics with 95% CIs
- `out/jmir_revised/performance_delta_mae.csv` — ΔMAE vs MCID (1 NRS point)
- `out/jmir_revised/lme_lr_test.csv` — mixed-model likelihood-ratio test
- `out/jmir_revised/within_patient_rho_by_rater.csv` — within-patient correlations
- `out/jmir_revised/wilcoxon.csv` — per-patient MAE comparisons with Holm correction

**Runtime:** ~3 min (parallelized across 13 outer folds)

### Classification Models (Table S4, Figures S1-S2)
```bash
python analysis/jmir_classification.py
```

**Threshold sensitivity:** binary ≥3, ≥4, ≥5, ≥6, ≥7  
**Multi-class:** 3-category (0-3/4-6/7-10, 0-4/5-6/7-10), 4-category (0/1-3/4-6/7-10)

**Outputs:**
- `out/jmir_revised/classification_ci.csv` — AUROC, balanced accuracy, macro-F1, κ with 95% CIs
- `out/jmir_revised/classification_permutation.csv` — permutation tests (1000 shuffles)
- `out/jmir_revised/confusion_3class.csv` — confusion matrices for 3-class clinical grouping

**Runtime:** ~10 min

### Stratified Analysis (Needle/Lidocaine Only)

Already included in `jmir_analysis.py` — subset to `category == "procedural"` (135 patient, 108 nurse/physician assessments).

**Key finding:** Physiological models fail completely (negative R²), context models weaken (R² drops to 0.01–0.17).

## Key Results

### Primary Regression (All Events, N=178/159/159)

| Model | Feature Set | Patient R² | Nurse R² | Physician R² |
|-------|-------------|------------|----------|--------------|
| Baseline | Training mean | −0.05 | −0.02 | −0.02 |
| Ridge | Physiological | −0.09 | −0.08 | −0.07 |
| Ridge | Context | **0.44** | **0.56** | **0.56** |
| Ridge | Phys+Context | 0.39 | 0.37 | 0.35 |

**ΔMAE (Physiology+Context vs Context Alone):**
- Nurse: +0.31 (95% CI 0.11 to 0.53) — CI excludes zero and MCID
- Physician: +0.31 (95% CI 0.14 to 0.51) — CI excludes zero and MCID

**Mixed-Model LRT (Does physiology add information beyond context?):**
- Nurse (all events): χ² = 3.19, p = .074 ❌
- All raters (needle/lidocaine): p > .05 ❌

**Within-Patient Spearman ρ (Context Models):**
- Nurse: 0.69 (95% CI 0.53 to 0.81)
- Physician: 0.59 (95% CI 0.39 to 0.74)
- Patient: 0.40 (95% CI 0.18 to 0.60)

### Stratified Analysis (Needle/Lidocaine Only, N=135/108/108)

| Model | Feature Set | Patient R² | Nurse R² | Physician R² |
|-------|-------------|------------|----------|--------------|
| Ridge | Physiological | **−0.08** | **−0.09** | **−0.15** |
| Ridge | Context | 0.01 | 0.17 | 0.10 |

**Within-patient ρ CIs all include zero** for physiological models in this stratum.

### Threshold Sensitivity

| Threshold | Physiology AUROC | Context AUROC |
|-----------|------------------|---------------|
| ≥3 | 0.66–0.75 | 0.81–0.89 |
| ≥4 | 0.57–0.65 | 0.72–0.83 |
| ≥5 | 0.50–0.59 | 0.67–0.78 |
| ≥6 | 0.54–0.61 | 0.65–0.73 |
| ≥7 | 0.50–0.57 | 0.59–0.67 |

**Permutation tests (physiology):** p < .05 at ≥4 and ≥5 for clinicians, but AUROC 0.50–0.65 (weak discrimination).

## Statistical Methods

- **Cross-validation:** Leave-one-patient-out (13 unique patients, some with 2-4 sessions)
- **Nested tuning:** Inner 4-fold GroupKFold (by patient) for algorithm/hyperparameter selection
- **Confidence intervals:** Patient-level cluster bootstrap (2000 resamples)
- **Statistical tests:** 
  - Wilcoxon signed-rank (per-patient MAE differences) with Holm correction
  - Mixed-effects likelihood-ratio test (lme4 in R)
  - Permutation test (1000 label shuffles, physiological features, fixed logistic regression)
- **Preprocessing:** Robust scaling within-session (median/IQR), no cross-contamination between folds
